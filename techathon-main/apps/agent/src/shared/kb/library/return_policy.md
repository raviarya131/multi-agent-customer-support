# Return & Exchange Policy

## Return window
Items can be returned within **30 days of the delivery date**. After 30 days,
returns are not accepted unless the item arrived damaged or defective.

## Item condition requirements
To be eligible for a return, items must be:
- Unworn and unwashed
- In original packaging with all tags still attached
- Free from odours, stains, or signs of use

Items that do not meet these conditions will be refused at our warehouse and
returned to the customer at their cost.

## Non-returnable items
The following cannot be returned:
- Final-sale / clearance items (marked at checkout)
- Downloadable or digital goods (licence keys, e-books)
- Hygiene items (socks, underwear, swimwear) once the hygiene seal is broken
- Gift cards

## Exchanges
We offer direct exchanges for a different size or colour of the same item,
subject to stock availability. The exchange window matches the return window
(30 days from delivery). To request an exchange, follow the same process as a
return and select "Exchange" rather than "Refund" in the portal.

## Return shipping
- Orders over $50: a prepaid return label is provided at no charge.
- Orders under $50: a $5.99 return-shipping fee is deducted from the refund.
- Damaged or defective items: always free return shipping, regardless of order value.

## How to start a return
1. Go to **My Orders** and select the order containing the item.
2. Click **Return / Exchange** next to the relevant item.
3. Choose a reason, select Return or Exchange, and confirm.
4. Print the prepaid label (or note the $5.99 fee if applicable) and drop the
   parcel at any carrier location.
5. Refunds are processed within 2–3 business days of the warehouse receiving
   the item, and the credit appears on the original payment method within
   5–7 business days after that.
